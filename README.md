# نظام الحضور والغياب لشعبة Special Chemistry
### Special Chemistry Attendance System

نظام جامعي حقيقي ومتكامل لإدارة الحضور والغياب لشعبة الكيمياء الخاصة (Special Chemistry) - كلية العلوم.

---

## 🌟 الميزات والمواصفات الأساسية

- **نظام Full-Stack مدمج مستقل**:
  - خادم Node.js / Express فائق السرعة مدمج مع قاعدة بيانات محلية نشطة (`/data/database.json`).
  - يعمل بدون أي قيود شبكية أو خدمات سحابية خارجية، وجاهز للتشغيل والنشر المباشر.
- **إدارة صلاحيات مبنية على الأدوار (RBAC)**:
  - المشرف الأكاديمي (`ADMIN`)
  - عضو هيئة التدريس / المحاضر (`DOCTOR`)
  - الطالب (`STUDENT`)
- **حساب المشرف الأكاديمي**:
  - الاسم: `محمد سمير عبدالعاطي`
  - كلمة المرور: `Chemist 2030`
  - إمكانية تغيير كلمة المرور فور الدخول وحفظها بأمان.
- **توليد كلمات مرور قوية للدكاترة**:
  - صيغة كلمة المرور: `CHEM + CourseCode + RandomPart` (مثال: `CHEM203-K7P4`).
  - عرض كلمة المرور لمرة واحدة للمشرف مع زر النسخ السريع، مع إمكانية Reset Password في أي وقت.
- **استيراد كشوف الطلاب بملفات Excel (`.xlsx`)**:
  - معالجة وفحص ملفات الإكسيل مباشرة بالواجهة الأمامية.
  - إظهار معاينة وإحصائيات شاملة (الإجمالي، الصحيح، التكرارات، الأخطاء، التوزيع على المجموعات) قبل الحفظ.
- **تسجيل دخول الطلاب الآمن**:
  - دخول مباشر بالاسم ورقم المجموعة مع التحقق الفوري من كشف الدفعة.
  - لا يتطلب كلمة مرور معقدة للطلاب.
- **جلسات حضور ذكية وتقنية QR Code**:
  - توليد رمز QR ديناميكي يتجدد مشفراً كل 30 ثانية لمنع تصوير الشاشة وإرسالها خارج القاعة.
  - قفل ذري يمنع تكرار تسجيل حضور الطالب في الجلسة ذاتها.
- **التحقق من النطاق الجغرافي (GPS Geolocation)**:
  - التحقق من تواجد الطالب داخل نطاق قاعة المحاضرة أو المعمل باستخدام معادلة Haversine (نصف قطر 80 متر).
- **تصدير التقارير والكشوفات**:
  - تصدير كشوف الحضور والغياب بصيغتي Excel و CSV بنقرة واحدة عبر المتصفح.

## 🛠️ التشغيل والإنتاج

```bash
# تثبيت الاعتماديات
npm install

# تشغيل خادم التطوير
npm run dev

# بناء المشروع للإنتاج
npm run build

# تشغيل المشروع في الإنتاج
npm start
```
سيعمل التطبيق على الرابط: `http://localhost:3000`.
